## 결과와 증거 범위

3개 원문 모두 HTTP 200으로 확인하고 현재 표시되는 본문을 대조했다. 과거 정책의 HTML 주석은 현행 근거로 사용하지 않았다. 삭제·접근 불가를 발견하지 않았다. 정책이 새로 바뀌었다고 입증할 과거 원문 비교본은 없으므로 정책 변경으로 단정하지 않는다. 확인된 문제는 현재 안내의 범위가 현행 원문보다 넓었던 부분이다.

원래 Seed checked_at은 보존한다. 별도 JSON 기록에 원문 URL·기관·HTML SHA256·53개 참조의 판단·전후 수정 필드·해당 주장 해시를 기록했다. 내용이 바뀌거나 접근 실패·미완료·미래 기준일인 기록은 검토 기한을 해제하지 않는다. 렌더링 날짜는 한국 날짜를 사용하고, source-health의 --as-of는 지정 날짜의 역사적 보고를 유지한다. 현재 검토 결과는 다음 명령으로 재현한다: node scripts/source-health.mjs --as-of=2026-10-17.
