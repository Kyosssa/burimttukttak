# Phase 9 유사 본문 수동 검토

2026-09-23 기준, `duplicateDisposalBodies`가 보고한 본문 완전 일치 묶음은 아래 11개 한 그룹이다. 검사는 계속 검토 경고로 유지한다. 이번 단계에서는 Seed의 배출 단계·주의사항·출처를 수정하지 않았다.

| 점검 품목 | 수정 | 판단 |
| --- | --- | --- |
| 침대프레임 (`bed-frame`) | 없음 | 품목별 단계·재질·수수료 차이를 원문에서 확인하지 못함 |
| 소파 (`sofa`) | 없음 | 품목별 단계·재질·수수료 차이를 원문에서 확인하지 못함 |
| 의자 (`chair`) | 없음 | 수거기관의 가구 제외 예시에 나오지만 별도의 배출 절차는 제시되지 않음 |
| 책상 (`desk`) | 없음 | 수거기관의 가구 제외 예시에 나오지만 별도의 배출 절차는 제시되지 않음 |
| 식탁 (`dining-table`) | 없음 | 품목별 단계·재질·수수료 차이를 원문에서 확인하지 못함 |
| 서랍장 (`drawer-chest`) | 없음 | 품목별 단계·재질·수수료 차이를 원문에서 확인하지 못함 |
| 옷장 (`wardrobe`) | 없음 | 수거기관의 장롱 제외 예시가 있으나 품목별 배출 절차는 제시되지 않음 |
| 책장 (`bookshelf`) | 없음 | 품목별 단계·재질·수수료 차이를 원문에서 확인하지 못함 |
| 화장대 (`vanity-table`) | 없음 | 품목별 단계·재질·수수료 차이를 원문에서 확인하지 못함 |
| 신발장 (`shoe-cabinet`) | 없음 | 품목별 단계·재질·수수료 차이를 원문에서 확인하지 못함 |
| 거울 (`mirror`) | 없음 | 가구와 다른 처리 단계를 뒷받침할 직접 근거를 확인하지 못함 |

검토한 공식 자료: [기후에너지환경부 분리배출 안내](https://www.xn--oy2b29bd3a601b.kr/front/bbsList.do?bbsId=BBS_0003)와 [E-순환거버넌스 폐가전 무상방문수거 안내](https://www.15990903.or.kr/portal/cnts/userGuide.do). 전자는 품목별 가구 처리 단계를 제시하지 않고 대형폐기물은 지자체 안내가 우선임을 밝힌다. 후자는 가구가 폐가전 수거 대상에서 제외된다고 안내하지만, 이 11개 각각의 배출 방법·수수료를 정하지 않는다. 따라서 같은 절차를 설명하는 본문을 단지 검색엔진용으로 다르게 쓰거나 근거 없는 분해·재질 지침을 추가하지 않았다. 개별 품목에 대한 관할 지자체의 직접 자료가 확보되면 사람 검토 후 수정한다.
