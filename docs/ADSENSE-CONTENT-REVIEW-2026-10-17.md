## 감사 방법과 전수 범위

`node scripts/audit-content.mjs --json`으로 색인 상세 124개와 가이드 11개를 전수 비교한다. 결과는 [JSON 감사 기록](./ADSENSE-CONTENT-REVIEW-2026-10-17.json)에 있다.

비교 대상으로 상세의 핵심 답변·배출 순서, 가이드의 도입·단계 본문만 사용한다. 품목명·별칭은 제거하며 메뉴·광고·공식 출처 목록·반복 경고·지역 공통 경고는 비교 입력에 넣지 않는다. 새 보조 설명으로 기존 본문의 반복 신호를 덮어 가리지 않는다.

문자 3-gram 유사성과 행동 집합(전지 분리/전용수거함/방문수거/관할 확인 등)으로 표현·순서가 달라진 후보도 찾는다. 이는 언어 의미를 완전히 이해하는 모델이 아니다. 같은 행동 집합이 같은 답변을 뜻하지 않으므로 사람의 품목·조건·근거 비교가 필요하다. 경고를 build 실패·자동 noindex·상태 변경으로 연결하지 않는다. 기존 완전 중복 gate도 유지한다.

- 150개 후보 쌍, 그중 106개 쌍은 기존 ‘품목명을 치환한 전체 본문’ 비교와 일치하지 않는다. **150개 불량 페이지 또는 106개 확정 결함을 뜻하지 않는다.**
- 이름을 제외한 핵심 답변·단계가 완전히 같은 경우는 가전 22개에 걸친 54개 쌍이다. 경고·보조 답변까지 같다는 뜻은 아니다.
- 예: 식기세척기/복사기는 핵심 절차가 같지만 복사기의 잉크·토너 주의사항은 실질적인 차이다. 경고를 제외한 감사 신호만으로 페이지를 삭제하면 안 된다.
- 가이드 본문 유사성 0.3 이상 후보는 없지만 연결 품목이 2개 이상 겹치는 가이드 쌍은 4개다. 문장 점수만으로 역할 중복이 없다고 결론 내리지 않고 아래에서 직접 비교했다.

## 사이트 전체 UX·운영 설명

- 홈→카테고리/가이드→상세, 상세→관련 품목/가이드 경로와 내부 링크를 검사했다. 여섯 상세의 다음 링크는 ‘다른 품목’만 나열하는 대신 사용자가 확인하려는 조건을 링크 문구에 적었다.
- 고정된 대표 목록을 검색량 근거 없이 ‘자주 찾는’이라고 표시하던 홈 제목을 ‘먼저 살펴볼 품목’으로 수정했다. 검색량 순위라는 의미를 없앴고 인기·급상승 수치를 만들지 않았다.
- About에 품목 상세/상황 가이드의 역할과 직접 수거 접수 서비스가 아니라는 사실을 명확히 했다.
- 출처 원칙에 검증의 범위, 확인일/수동 재검토 일정, 실시간 자동 갱신이 아니라는 운영 사실을 설명했다.
- 공개 HTML 검사에서 준비 문구·빈 광고 placeholder·깨진 내부 링크는 발견되지 않았다. 검색 입력 전 화면은 검색 기능이며 자체 폐기 답변으로 간주하지 않았다.
- 쿠팡은 기존대로 홈+색인 상세 125개에 최대 한 wrapper, 본문·공식 출처 뒤/푸터 전에 배치되고 iframe 생성 전 숨긴다. 실패 시 정리 동작과 고지는 기존 테스트를 유지한다. 개수를 늘리거나 배너를 제거하지 않았다.
- AdSense loader는 기존처럼 전체 HTML에 있고 실제 AdSense 슬롯·Auto ads는 없다. 검색/404/hold의 noindex는 검색 색인 정책이지 AdSense 심사 제외를 보장하지 않는다. 이것이 반려 원인이라고 확인된 것은 아니며 심사 대상 범위를 별도 고려해야 한다.

### 해결하지 못했거나 억지로 바꾸지 않은 범위

1. 소형·생활가전 공통 핵심 본문 22개는 일부 경고/기존 질문에 실제 차이가 있지만 공통 절차 비중이 크다. 공유기의 경로 선택을 개선했어도 모든 모델·부속품의 고유 질문을 해결했다고 보지 않는다. 제조사/공식 기관의 직접 근거 없이 분해·배터리 위치·어댑터 처리·임대 반환 지침을 만들지 않았다.
2. 음식물의 뼈·껍질 등은 같은 지역 규칙을 공유한다. 같은 결론 자체는 결함이 아니다. 개별 질문에 없는 건강 위험·안전 조치·전국 비용을 추가하지 않았고 지역 한정 표시를 유지했다.
3. 형광등/LED 등 짧은 답변은 기존 경고가 중요한 보조 정보다. 길이가 짧다는 이유만으로 안전 설명을 증식하지 않았다.
4. 가구 hold 11개·needs_research 14개는 그대로다. 이름만 바꾸어 차별화하거나 hold를 해제하지 않았다.
5. source-health는 2026-10-17 기준 기존 출처 3개(누리집/폐가전 서비스/장소 지도), 53개 Seed 참조의 재검토 예정일 경과를 보고한다. 새 보조 설명의 직접 원문을 읽었다고 기존 53개 전체 주장의 확인일을 갱신하지 않았다. `ewaste-faq` 등 Seed 외 보조 데이터의 검토 일정은 기존 source-health 집계에 포함되지 않는 한계도 남아 있다.

## 재신청 전 남은 필수 확인

1. 로컬 변경을 검토하고 별도 배포 승인 후 운영 URL에서 내용·canonical·실제404·검색·PC/모바일 광고/푸터를 smoke test한다. 현재 Production은 여전히 7544e19이며 이번 수정은 반영되지 않았다.
2. 공통 가전군의 제품별 해결 질문을 실제 유입 질문/공식 FAQ와 대조한다. 근거로 구별할 수 없으면 공통 지침임을 유지하고 후속 처리 방안을 사람 검토한다. 이번에는 대량 noindex/삭제/301을 하지 않았다.
3. 기한 경과한 출처의 실제 적용 내용과 Seed 외 질문·가이드 근거 일정을 재검토한다. 주기 경과가 곧 정보 오류라는 뜻은 아니지만 확인일을 실제 검토 없이 새로 쓰면 안 된다.
4. AdSense 계정의 실제 반려 안내·정책 센터에서 추가 항목이 있는지 사용자가 확인하고, 반영된 운영 사이트를 기준으로 재신청 여부를 결정한다. 문제 URL·최소 글자 수·필요 페이지 수·재신청 대기 기간을 임의로 만들지 않는다.

[Google 공식 비승인 안내](https://support.google.com/adsense/answer/81904?hl=ko)는 콘텐츠 품질과 탐색을 함께 보며 사이트의 여러 페이지가 심사될 수 있다고 설명한다. 공식 근거를 인용했다는 사실만으로 품질 승인을 보장하지 않는다. 어떤 항목이 이번 반려를 유발했는지는 확인할 수 없으며 이번 보강으로 승인을 보장하지 않는다.
