# Phase 8 수동 출처 검토 (2026-09-23)

이번 검토는 공개된 지자체 원문을 사람이 읽고 Seed에 반영했다. 출처를 자동 수집하거나 운영 중 자동 승격하지 않는다. 아래의 분류와 절차는 해당 지자체의 기준이다. 다른 지역의 배출 방법·수수료·신청 방식은 관할 지자체에서 확인해야 한다.

세 URL의 원문을 2026-09-23에 확인했다. 출처 레지스트리의 검토 주기 30일에 따라 다음 수동 검토 예정일은 2026-10-23이다. 이 날짜는 자동 갱신일이 아니다.

## 승격 보류

| 후보 | 이번에 보류한 이유 |
| --- | --- |
| 주방칼, 가위 | 날붙이 안전 포장과 지역별 배출 경로를 함께 뒷받침할 직접 원문을 이번 검토에서 확보하지 못함 |
| 수저, 젓가락, 유리컵, 텀블러, 보온병, 수세미 | 소재와 분리 가능 여부가 다양한데 각각의 완성품 배출 판단을 뒷받침할 직접 원문을 확보하지 못함 |
| 택배봉투 | 비닐·종이·복합재질에 따라 달라 단일 답변으로 승격할 수 없음 |
| 새우껍질 | 확인한 서초구 원문은 게·가재를 명시하지만 새우를 직접 명시하지 않음 |
| 티백 | 원문은 차 찌꺼기를 설명하지만 티백의 포장재와 내용물을 함께 처리하는 방법은 명확하지 않음 |
| 신발, 가방 | 확인한 파주시 대형폐기물 표는 신발 혼합 묶음과 여행용 가방만 명시하므로 일반적인 단일 신발·모든 가방으로 일반화할 수 없음 |
| 면도기, 샤워기헤드, 변기커버 | 재질·부품에 따른 직접 배출 근거를 확보하지 못함 |
| 라이터, 화장품, 향수, 매니큐어 | 잔여 내용물 및 안전 주의가 필요한데 완성품별 공식 처리 근거를 확보하지 못함 |

기존 가구 11개 품목의 `summary`·`steps`·`warnings`가 완전히 동일한 점은 새 검증의 편집 검토 경고로 남긴다. 이번 Phase 8에서 기존 공식 출처의 내용을 재작성하지 않았으며 후속 수동 검토가 필요하다.
