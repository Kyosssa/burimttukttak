## v1.1 추천

### "왜 이렇게 버려요?"
정답 카드 아래 1~2문장 근거 설명.
예: 재질/재활용 공정 때문에 무엇을 분리해야 하는지.
공식 근거가 있을 때만 작성.

### "같이 헷갈리는 품목"
related_items를 단순 카드가 아니라 비교형으로:
- 후라이팬 → 냄비 / 유리뚜껑
- 건전지 → 보조배터리
- 형광등 → LED전구

검색 체류와 내부링크에 동시에 도움.

### 최근 검색
브라우저 localStorage에 최대 5개.
서버 전송 없음.
사용자가 직접 삭제 가능.
개인화 서버/회원가입 필요 없음.

### 링크 복사
`이 배출방법 공유하기`
Web Share API 지원 시 공유, 아니면 URL 복사.
SEO/서버비 영향 없음.

## v2

### 지역 선택
사용자 위치 자동 요구하지 말고
시/도 → 시군구 직접 선택을 기본으로.

### 대형폐기물
지역별 신고링크, 비용, 배출일.

### 내 주변 배출장소
공식 데이터 확보 후 지도.
정확 주소/위치권한은 기능 사용자가 명시적으로 선택할 때만.

### 공식 데이터 변경알림
source diff → 검토 큐.

### 품목 300~500개 확대
missing search 순위 + 검색 데이터 + 공식자료 확보 가능성을 합쳐 선정.

## 지금 넣지 않기
