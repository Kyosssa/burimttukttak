# 버림뚝딱 콘텐츠 수명주기 / 변경감지 v1

## 목표
버림뚝딱의 가장 큰 리스크는 '처음에는 맞았지만 나중에 공식 기준이 바뀌는 것'이다.
따라서 verified는 영구 상태가 아니라 '마지막 공식 확인 시점이 기록된 상태'로 취급한다.

## 상태

### `needs_research`
아직 공개할 수 없음.

### `verified`
현재 공식 근거 확인 완료.

### `review_due`
마지막 확인 이후 권장 검토 주기를 넘김.
페이지를 즉시 내릴 필요는 없지만 운영 큐에 올린다.

### `source_changed`
공식 출처의 제목/핵심 텍스트/응답 상태가 변경됨.
자동으로 배출법을 수정하지 않고 사람 검토를 요구한다.

### `retired`
더 이상 유효하지 않은 품목/서비스.
기존 URL 처리정책에 따라 301 또는 410/404 검토.

## 품목별 권장 필드

```json
{
  "verified_at": "2026-09-22",
  "next_review_at": "2026-10-22",
  "verification_status": "verified",
  "source_fingerprints": [
    {
      "source_id": "me-recycling-guideline",
      "checked_at": "2026-09-22",
      "etag": null,
      "last_modified": null,
      "content_hash": null
    }
  ]
}
```

v1 공개를 위해 content_hash까지 반드시 구현할 필요는 없다.
우선 `verified_at + source registry + 링크 상태 검사`만으로 충분하다.

## 자동검사 원칙

자동화가 할 일:
- URL 2xx/3xx 여부
- 최종 URL 변경 여부
- 페이지 제목/핵심 키워드 존재 여부
- 마지막 성공 확인시각
- 실패 횟수
- diff 생성

자동화가 하지 않을 일:
- 배출방법 본문 자동 변경
- `verified` 자동 승격
- 출처가 바뀌었다는 이유만으로 페이지 자동 삭제

## 검토주기

- 폐가전 수거 서비스: 14일
- 공식 품목 포털: 14일
- 고시/지침: 30일
- 지역별 수수료/배출일(v2): 7~14일 권장

## 소스 장애 처리

1회 실패:
- 공개페이지 유지
- 로그만 기록

연속 3회 실패:
- 운영 경고
- source_changed/review_due 후보

공식 자료가 폐기되고 새 URL이 확인된 경우:
- source URL 갱신
- 실제 기준 변경 여부 별도 검토
- 품목 verified_at 재설정은 내용 검토 후에만 수행

## 페이지 표시

사용자에게는:
`정보 확인일: 2026.09.22`

오래된 정보 표시 정책은 향후 데이터가 충분히 쌓인 뒤 도입.
초기에는 사용자에게 불필요한 경고를 남발하지 않는다.
