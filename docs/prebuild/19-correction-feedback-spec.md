# 버림뚝딱 정보 수정 제보 흐름 v1

## 목적
공식 기준 변경이나 지역 차이를 사용자가 발견했을 때 빠르게 제보할 수 있게 한다.

v1에서는 별도 계정 시스템/대형 폼을 만들지 않는다.

## UI

품목 페이지 하단:

`정보가 달라졌나요?`
`공식 기준이 변경되었거나 잘못된 내용을 발견했다면 알려주세요.`

[수정 제보하기]

## v1 구현 선택

가장 단순:
- `mailto:` 운영 이메일

자동 포함 subject:
`[버림뚝딱 수정 제보] 후라이팬`

본문 템플릿:
- 품목:
- 어떤 내용이 다른가요?
- 확인한 공식 출처가 있다면 URL:
- 추가 설명:

이름/전화번호 요구하지 않음.

## v1.1 이후 D1 form 고려

저장:
- item_slug
- report_type
- message
- source_url(optional)
- created_at
- status

저장하지 않음:
- 이름
- 전화번호
- 정확 위치
- IP를 앱 데이터로 영구저장

스팸이 문제가 되면 Turnstile 도입 검토.

## 운영 상태

- new
- reviewing
- accepted
- rejected
- duplicate

제보만으로 콘텐츠 자동수정 금지.
공식 자료 재확인 후 반영.
